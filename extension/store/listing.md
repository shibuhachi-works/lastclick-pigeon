## 詳細な説明

```
Markdown で書いた記事を、note に貼り直す手間をなくす Chrome 拡張です。
md ファイルと見出し画像を選ぶだけで、note の下書きができあがります。
公開ボタンは押しません。

■ 省ける手間
これまで手でやっていた、この作業がまとめてなくなります。
・タイトルを入れ直す
・本文を貼ってから、見出し・太字・箇条書きを整え直す
・見出し画像をアップロードして、トリミングを保存する
・ハッシュタグを 1 つずつ打つ
・マガジンに追加する
記事ごとに繰り返していた作業が、ファイルを選ぶ 1 回で済みます。

■ 使い方
1. 拡張のウィンドウに md ファイルと見出し画像をドラッグ＆ドロップ(ボタンから選んでも可)
2. 「note の下書きを作成」を押す
3. note のエディタが新しいタブで開き、タイトル・本文・見出し画像が入ったところで止まる
4. 本文を確かめて、右下のバナーの「公開設定を入れる」を押す
5. ハッシュタグとマガジンが入ったところで止まる
6. 内容を確かめて、自分で「投稿する」を押す
タイトル・ハッシュタグ・マガジンは記事ファイルの先頭に書いておけば自動で入ります。
入れる前に画面で直すこともできます。
本文の確認を飛ばして、公開設定まで一気に進む設定もあります。

■ 公開ボタンは押しません
この拡張は、設計上、投稿・公開ボタンを一切押しません。
下書きのまま止まるので、公開前に必ず自分の目で確かめられます。
最後の 1 クリックはあなたが行います。

■ 安心して使えるように
・note のパスワードや Cookie には触れません
　ログイン済みの note のタブの中で動くだけです
・サーバーを持ちません
　記事はあなたの Chrome の中に一時的に置かれ、note 以外には送られません
・GitHub のトークンは、上級者向けの設定で private リポジトリの記事を読むときだけ任意で使えます
　GitHub(raw.githubusercontent.com)以外には送りません

■ 記事に使える書き方
見出し・太字・箇条書き・引用・コード・リンクは、そのまま note に入ります。
表は note 側が対応していないため、箇条書きに書き換えてください。
見出し画像は 1280×670px(note の推奨サイズ)にしておくと、そのまま全体が使われます。

■ 注意
・note の運営元とは関係のない、非公式のツールです
・note の画面構成が変わると動かなくなることがあります
　その場合はサポート URL のお問い合わせから、ポップアップの「診断」で取れるレポートを添えてご連絡ください
・ソースコードは GitHub で公開予定です(MIT ライセンス)
```

## 単一の目的(Single purpose)

```
note.com のエディタに、ユーザーが選んだ Markdown ファイルの記事を下書きとして入力すること。公開ボタンは押さない。
```

## 権限の理由(Permission justification)

| 権限 | 理由 |
|---|---|
| `storage` | 組み立てた記事(タイトル・本文 HTML・画像)を、ポップアップから note のタブへ渡すために一時的に保存する。任意の GitHub トークンと設定もここに保存する。外部には送らない |
| `clipboardWrite` | 「診断」ボタンで、note の画面の入力欄・ボタンの一覧(認証情報や本文を含まない)をクリップボードにコピーし、不具合の報告に使えるようにする |
| ホスト権限 `https://note.com/*`, `https://editor.note.com/*` | note のエディタのページで content script を動かし、タイトル・本文・画像・ハッシュタグ・マガジンを入力するため |
| ホスト権限 `https://raw.githubusercontent.com/*` | (1) 記事の Markdown と見出し画像を GitHub から読む(ユーザーが URL を渡したときだけ)、(2) note の画面構成の変更に追従するためのセレクタ定義(JSON。コードではない)を読む |

## リモートコード(Remote code)

```
使用していません。GitHub から読むのはセレクタ定義の JSON と、ユーザーが指定した Markdown/画像だけで、コードは実行しません。
```

## データの使用(Data usage)

- 収集するデータ: **なし**(個人を特定できる情報・健康・金融・認証情報・個人の通信・位置情報・閲覧履歴・ユーザーの操作・ウェブサイトのコンテンツ、いずれも収集・送信しない)
- 認定(3 つのチェック): すべて「はい」
  - 承認された用途以外でデータを販売・使用しない
  - 単一の目的と関係のない用途でデータを使用・転送しない
  - 信用力の判断や融資の目的でデータを使用・転送しない
