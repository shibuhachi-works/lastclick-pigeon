# ストア画像

- `../icons/icon.svg`: 文字なしのアイコン原稿。全サイズ(16/32/48/128)で同じ 1 原稿。鳩を枠いっぱいに置き、くちばしに紙片。16px でも潰れないようカーソルは入れない(紙片の線は 3.5px)。`npm run icons` で PNG に書き出す。
- `promo-small.svg`: 440×280 の文字なし素材。鳩を従来比約15%拡大し、紙と合わせて左1/3の上下中央に配置。紙はくちばし側に置き、体と重ねない。右2/3は文言用の余白。
- `marquee.svg`: 1400×560 の文字なし素材。ブラウザ内は見出し1本と箇条書き3本。小さな手は右下から入り、ボタンは全体を見せる。カーソルはボタン上方に間隔を空けて置く。右半分は文言用の余白。
- `promo-small.png` / `marquee.png`: 今回指定された掲載文を重ねた完成画像。SVG に文字は含めず、文言は `screenshots.mjs` で管理する。
- `screenshot-1.png` 〜 `screenshot-5.png`: ストアのスクリーンショット(1280×800、アルファなしの PNG、最大 5 枚)。Shazam のストア掲載のように「大きな見出し + 画面」で魅力を伝える。1: ポップアップ(入力例つき)、2: 公開ボタンは、あなたが押す(マーキーの素材を背景なしで使い、本物のバナーを重ねる)、3: md ファイルと見出し画像を、ドラッグ＆ドロップするだけ(ドロップ中のポップアップ)、4: 手でやらなくていいこと、5 つ、5: 触らないもの、3 つ。note の画面そのものは撮れないので、拡張の実際の部品と文字なしの素材で組む。

3素材の鳩は同じパスを使用する。背景のグラデーションは従来どおり。小さなプロモタイルの3行目は不透明度0.9で描画する。

生成時の比率指定よりもストアの提出寸法を優先し、完成画像はそれぞれ 440×280、1400×560 にしている。文言内の空白と句読点は指定どおりで、長い見出しと説明は読みやすい位置で折り返す。

リポジトリ直下で `npm ci && npx playwright install chromium`、続けて `extension/` で `npm ci && npm run icons && npm run build && npm run screenshots`。既存の Chromium を使う場合は `PLAYWRIGHT_CHROMIUM_PATH` に実行ファイルのパスを指定できる。日本語の描画には Noto Sans CJK JP を推奨する。
