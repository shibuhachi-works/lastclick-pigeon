## はじめに

この md は `tools/draft.ts` の動作確認用サンプルです。
front matter(先頭の `---` で囲まれた部分)に公開に必要な情報を全部まとめます。

## 使える記法

note のエディタに貼り付けて再現できるのは、だいたいこのあたりです。

- 見出し(`##` と `###`)
- 箇条書き・番号付きリスト
- **太字**
- > 引用
- 区切り線

```
コードブロックも貼れます
```

## 使えない記法

note は Markdown の**表に非対応**です。表が必要なときは、AI に生成させる段階で
「表は箇条書きに展開する」とプロンプトに入れておくのが一番安上がりです。
