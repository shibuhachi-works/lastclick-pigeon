# v0.1.1

Chrome ウェブストアで公開した最初の版です(2026-10-30)。

## できること

- md ファイルと見出し画像を選ぶだけで、note の下書き(タイトル・本文・見出し画像・ハッシュタグ・マガジン)を組み立てます
- 公開ボタンは押しません。本文を入れたところと、公開設定を入れたところの 2 回で止まり、最後は自分で確かめて押します
- note の Cookie・パスワードには触れず、記事を送るサーバーも持ちません

## 入手

- Chrome ウェブストア: https://chromewebstore.google.com/detail/lastclick-pigeon-for-note/jomapffkhcdpnodaffobmpfofnnaihnd
- 使い方は [extension/README.md](https://github.com/shibuhachi-works/lastclick-pigeon/blob/v0.1.1/extension/README.md)、プライバシーポリシーは [docs/PRIVACY.md](https://github.com/shibuhachi-works/lastclick-pigeon/blob/v0.1.1/docs/PRIVACY.md)

## この版に含まれるもの

- Chrome 拡張(MV3)と、開発用の Playwright 版
- note の画面が変わったときは、`selectors/note.json` を直すだけで全員に届きます(ストアの再申請は不要)
